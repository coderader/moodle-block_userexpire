Features:

This block gives the user a visual block about the expiration of enrollment. Latest for version 4 and up.  
Should work above that as well.  Pretty simple, but very needed. 

Manual Installation:
1- Place the userexpire folder (if you have downloaded zipped file then you have to unzip 
it) into the blocks folder under the root of your Moodle installation.
2- Go to the notifications page, and Moodle will automatically install this new
block. 

Once installed, turn editing on and add the block "User Expire block".
